# Mistake Organization Rules

## Core rules

- Preserve the original question as much as possible.
- Preserve the user's wrong answer, wrong reasoning, or original confusion.
- Do not only provide the correct answer.
- Always explain the correct reasoning process.
- Separate direct cause from deeper cause.
- Connect each mistake to one or more knowledge points.
- Identify the trap or misleading condition in the question.
- Generate review questions for future active recall.
- If information is incomplete, clearly mark what is missing.

## Required analysis

For each mistake, identify original question, wrong answer or reasoning, correct answer, solution process, direct cause, deep knowledge gap, related knowledge points, similar-question recognition pattern, and review questions.
