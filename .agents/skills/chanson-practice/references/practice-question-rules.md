# Practice Question Generation Rules

## Core rules

- Generate original questions.
- Follow postgraduate entrance exam question style when requested.
- Do not copy real past exam questions unless the user provides them.
- Respect the user's requested number of questions exactly.
- Respect the user's requested difficulty.
- If no count is specified, default to 5 questions.
- If no difficulty is specified, default to medium.
- Base questions on selected chapter notes, mistake notes, or specified knowledge points.
- Include answers and explanations unless the user asks for questions only.
- Each question must have a clear tested knowledge point.
- Each question should include a trap, misconception, or reasoning focus when appropriate.

## Source-specific rules

From chapter notes, cover concept understanding, mechanism explanation, calculation/application, misconception identification, and comprehensive application.

From mistake notebooks, prioritize repeated weak points, direct mistake causes, deeper misconceptions, similar-question recognition, and trap resistance.

From specified knowledge points, create a difficulty gradient unless the user requests otherwise.
