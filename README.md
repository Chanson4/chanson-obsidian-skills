# Chanson Skills Library

This library contains four independent skills that work together as a learning workflow for Codex and Obsidian-based study vaults.

Install by copying the `.agents/skills` folder into a Codex project, or copy each skill directory into an existing `.agents/skills/` directory.

## Skills

- `chanson-directory`: create safe learning vault folders and Markdown skeletons.
- `chanson-notes`: distill AI learning dialogues into study-note drafts while preserving original user questions.
- `chanson-mistakes`: turn raw wrong questions into reviewable mistake-note drafts.
- `chanson-practice`: generate targeted exam-style practice questions from notes, mistakes, or specified knowledge points.

## Obsidian skill collaboration

Chanson skills focus on learning content and structure. Obsidian-related skills should handle final Obsidian formatting, frontmatter, wikilinks, tags, callouts, embeds, and vault-specific insertion style.
