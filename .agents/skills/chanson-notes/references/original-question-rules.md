# Original Question Rules

- Keep the user's real phrasing when it reveals the learning obstacle.
- If the original question is long, quote the key part and summarize the rest.
- If several user questions point to one knowledge point, group them and keep all important variants.
- Add a "问题本质" line that explains the cognitive gap behind the question.
- If the question contains a misunderstanding, preserve it and convert it into "易错点与纠偏".
- Do not rewrite away the learner's confusion; the confusion is part of the learning asset.
