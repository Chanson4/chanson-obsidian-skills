# Chanson Library Protocol

These skills belong to the same Chanson learning skill library.

## Shared responsibilities

- Chanson skills optimize learning content, structure, and review value.
- Obsidian-related skills own final Obsidian formatting, frontmatter, wikilinks, tags, callouts, embeds, and vault-specific insertion style.
- When the user requests final Obsidian writing and an Obsidian skill is available, prepare a clear handoff instead of duplicating full Obsidian formatting logic.
- If no Obsidian skill is available, output clean plain Markdown and clearly label it as a draft.

## Handoff fields

When handing content to an Obsidian skill, include target subject, chapter, target note, content draft, preservation requirements, suggested related concepts, suggested tags, and insertion preference.
