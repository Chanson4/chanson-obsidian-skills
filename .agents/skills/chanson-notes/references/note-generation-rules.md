# Note Generation Rules

## Preserve

- Original user questions.
- Questions that expose confusion or misconceptions.
- Explanations that turn confusion into understanding.
- Derivations, examples, analogies, calculations, and correction paths.
- Exam-facing conclusions and common traps.

## Remove or compress

- Greetings and repeated confirmations.
- Repeated AI answers that do not add new understanding.
- Tool chatter, irrelevant detours, or failed attempts.
- Overlong prose that can be rewritten into a clearer explanation.

## Rewrite standard

Every important knowledge unit should include:

1. Original question.
2. Underlying confusion.
3. Core conclusion.
4. Why it is true.
5. Key reasoning process.
6. Misconception and correction.
7. Exam-facing pattern.
8. Review question.

If a knowledge point only has a conclusion, expand the explanation using the dialogue context.
